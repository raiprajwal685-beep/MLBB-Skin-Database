# MLBB-Skin-Database

Catalogue metadata for the Sjector demo app.

## Manifest

- `manifest.json` is the catalogue source consumed by Sjector.
- Each skin entry includes `id`, `heroName`, and `skinName`.
- Optional `archiveLabel` and `resourceMetadata` fields record information observed in supplied archives.

## Asset handling

The supplied archives contain proprietary Mobile Legends game resources (Unity bundles and audio banks). The repository stores catalogue metadata only; the original binary game assets are not redistributed here.
